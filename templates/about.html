About Us

This task management system is a web-based application designed to help users organise, track, and manage their daily tasks efficiently. It allows users to create, view, update, and delete tasks, as well as assign priorities, set due dates, and categorise them for better planning. The application is built using Flask for the backend with SQLite for data storage. The frontend is developed with HTML, CSS, Bootstrap, and JavaScript, providing a responsive and user-friendly interface across devices. This project was developed as a COS Group 5 assignment to demonstrate practical web development concepts, including frontend design, backend routing, database management, and version control with GitHub. Our goal was to create a clean, efficient, and easy-to-use task management system that helps users stay organised and productive. .
